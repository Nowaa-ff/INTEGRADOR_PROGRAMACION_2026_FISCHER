# Examen Integrador de Programación I

## Objetivo

El objetivo de este examen es evaluar los conocimientos adquiridos en la materia Programación I a lo largo del cursado del año 2026. El mismo comprende los siguientes temas:

- Fundamentos de Python (tipos de datos, definición de variables, input, etc...)
- Estructuras condicionales (if, elif, else)
- Estructuras iterativas (for, for _ in range(), while)
- Estructuras de datos múltiples (listas, matrices, diccionarios)
- Funciones
- Módulos e importación (import, separación de responsabilidades entre archivos)

## Formato de entrega

Para entregar el examen integrador, se debe trabajar sobre un fork del repositorio proveído por los profesores. EL FORK DEBE CONTENER EL APELLIDO DEL ALUMNO:

INTEGRADOR_PROGRAMACION_2026_APELLIDO
